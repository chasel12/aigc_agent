# Compose Director - 16:9横屏短剧

## 职责
合成最终视频：静帧拼接+字幕渲染+格式输出。

## 输出规范
- 分辨率：1920×1080
- 画面比例：16:9
- 编码：H.264
- 格式：mp4

## 字幕规范
- 位置：底部偏下居中
- 样式：白色字体+黑色描边
- 字号：适中，不占核心表演区域
- 字体：微软雅黑（msyh.ttc）

## 合成流程
1. 按剪辑决策顺序拼接场景图
2. 每张图持续对应时长
3. 渲染字幕叠加
4. 输出最终mp4

## 质量检查
- [ ] 画面比例16:9
- [ ] 分辨率1920x1080
- [ ] 字幕不遮挡人物面部
- [ ] 文件可正常播放
