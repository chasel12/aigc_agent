# Scene Director - 16:9横屏短剧

## 职责
将剧本转化为多机位分镜清单，输出结构化JSON storyboard。

## 核心规则
1. 每场对话拆分≥2个不同机位/角度镜头
2. 景别配比：中景>过肩>近景特写，穿插环境空镜
3. 遵循影视三分法，人物视线预留呼吸空间
4. 镜头运动：缓慢横移/推镜/轻微环绕
5. 同一场景不同机位交替剪辑，弥补无i2v的短板

## 16:9分镜清单格式
每条分镜包含：
- `镜号`：顺序编号
- `时长`：4-8秒
- `景别`：全景/中景/近景/特写/过肩
- `机位`：正面/侧面/背面/俯拍/仰拍+角度
- `角色ID`：出场角色
- `台词`：对白或旁白
- `正向提示词`：含16:9前缀+角色描述+场景+构图+光线
- `负面提示词`：全局禁令
- `镜头运动`：推/拉/横移/环绕/固定

## 检查清单
- [ ] 每25秒内有情绪推进
- [ ] 同段对话有景别切换
- [ ] 构图留白，人物不满画
- [ ] 负面提示词覆盖全部禁令
