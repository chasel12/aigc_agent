# 16:9横屏电影感AI短剧导演约束

## 适用范围
通义万相静态剪辑方案（无i2v/无Seedance），16:9横屏B站长视频短剧。

---

## 1. 画幅与基础参数
- 画面比例严格 **16:9**，分辨率 **1920×1080**
- 禁止纵向构图，所有画面按宽银幕电影构图设计
- 单镜头时长区间：**4～8秒**
- 每25秒内必须安排一次剧情情绪推进
- 不依赖Ken Burns静态缩放充当动态

## 2. 镜头语言规范（横屏核心）
1. 景别配比：**中景 > 过肩镜头 > 近景特写**，合理穿插全景/环境空镜
2. 双人对话优先使用【过肩镜头】，不要无脑正反打特写
3. 镜头运动：缓慢横移、缓慢推镜、轻微环绕（静态图中描述即可）
4. 构图标准：遵循影视三分法，人物视线预留画面呼吸空间
5. 同一对话段落拆分多个不同机位镜头剪辑，弥补无i2v的短板

## 3. 叙事结构（三幕式）
先导片结构：
> 氛围铺垫 → 危机冲突爆发 → 能力觉醒 → 代价伏笔 → 结尾悬念钩子

侧重人物情绪、氛围感塑造，不需要十几秒一次密集反转。

## 4. 角色一致性规范
1. 所有角色首次登场保存标准定妆参考图（正面半身）
2. 全部分镜生图强制挂载角色参考图描述
3. 五官、脸型、发型、服装与参考图保持高度统一
4. 画面崩坏自动重试1次，微调提示词重绘

## 5. 通义万相 16:9 专用提示词模板

### 正向基础前缀（每条分镜强制套用）
```
16:9宽银幕，国产都市写实短剧，院线电影布光，自然皮肤纹理，真实毛孔，镜头景深，电影感色彩，宽幅构图，画面具备空间纵深感，清晰对焦
```

### 全局负面提示词（每条分镜强制附加）
```
卡通，动漫，手绘，插画，塑料数字人脸，过度美颜，假面，畸形五官，扭曲手部，画面裁切，纵向构图，水印，低分辨率，多余肢体
```

### 角色描述模板
```
22岁清秀计算机男生，黑框眼镜，格子衬衫，五官严格匹配角色参考图
```

## 6. 输出格式
结构化JSON分镜清单，字段：
```json
{
  "镜号": 1,
  "时长": 5,
  "景别": "中景",
  "机位": "正面偏左15°",
  "角色ID": "linchen",
  "台词": "九点三十二分，我，林辰，终于拿到了大厂offer。",
  "正向提示词": "...",
  "负面提示词": "...",
  "镜头运动": "缓慢推镜"
}
```

## 7. 当前硬件限制适配（仅有通义万相）
1. 不调用图生视频工具
2. 同一场对话设计多个机位、角度、微表情不同的镜头交替剪辑
3. 合理增加环境空镜过渡，提升电影质感
4. 静帧剪辑节奏：用景别/角度切换制造动态感

## 8. 永久禁止行为
- 照搬9:16竖屏怼脸特写思维
- 大量超长固定静态画面形成幻灯片
- 人物塞满画面、无构图留白
- 频繁极端快速切镜
- 画面强行纵向构图
- 忽略角色参考图导致人物变脸
